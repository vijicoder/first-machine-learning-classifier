# First Machine Learning Classifier

## Project: Titanic Passenger Survival Prediction

This project builds and evaluates a Decision Tree Classifier using Scikit-learn.

### Prediction question
Can a passenger's ticket class, sex, age and fare help predict whether they survived the Titanic disaster?

### Project requirements covered
- Train/test split using `train_test_split`
- Model training with Scikit-learn
- Accuracy score
- Confusion matrix
- Mean squared error (MSE)
- Baseline comparison
- Decision tree depth comparison to discuss overfitting
- Feature importance and written observations

### Files
- `first_machine_learning_classifier.ipynb` — complete notebook
- `README.md` — project details and running instructions
- `requirements.txt` — required Python libraries

### How to run
1. Extract this ZIP file.
2. Upload the notebook to Google Colab or open it in Jupyter.
3. Run the cells from top to bottom.
4. Read the actual outputs and complete the observation blanks at the end.
5. Save the executed notebook before submitting its share link.

The notebook uses the Seaborn Titanic dataset. An internet connection may be needed to load it the first time.

**Note:** Results are generated when you run the notebook. No accuracy values have been made up.
